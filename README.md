## ✨ Возможности

### 🎵 Мультимедийный остров
- **Живая мини-обложка альбома**: аккуратная миниатюра трека прямо в свернутой челке.
- **Динамический эквалайзер**: полосы визуализатора адаптируются под ритм и окрашиваются в доминирующий цвет текущей обложки альбома.
- **Бегущая строка (Marquee)**: плавный скроллинг длинных названий треков и артистов с деликатными масками затухания.
- **Поддержка плееров**: нативная интеграция через MediaRemote с Apple Music, Spotify, Яндекс Музыкой, YouTube, Telegram и браузерами.
- **Полноразмерная панель**: перемотка скраббером, громкость, shuffle/repeat и избранное при раскрытии.

### ⌨️ Touch Bar Pro
- **Постоянная интеграция**: модальный Touch Bar не закрывается при кликах по экрану.
- **Управление медиа**: кнопки воспроизведения/паузы и карточка текущего трека в цвет обложки.
- **Кнопка закрепа (Pin)**: закрепление острова прямо с сенсорной панели.
- **Быстрый переход**: переключение между разделами челки в одно касание.

### ⚡ Встроенные инструменты
- **🔍 Текст с экрана (OCR)**: выделите прямоугольную область в любом месте экрана — текст мгновенно распознается через Apple Vision и скопируется в буфер обмена.
- **⏱ Таймер**: удобный обратный отсчет с отображением оставшегося времени прямо на челке.
- **🎚 Микшер приложений**: раздельная регулировка громкости конкретных приложений независимо от общего звука macOS.

### 📂 Полка файлов & Буфер обмена
- **Полка (Shelf)**: временное хранилище файлов у верхней грани экрана для быстрого drag-and-drop.
- **История буфера**: умный журнал скопированных текстов с поиском и быстрой повторной вставкой.

### 🖥 Поддержка всех экранов и Fullscreen
- Автоматическое выравнивание по физическому вырезу (Notch) на дисплеях MacBook Pro.
- Корректная работа на полноэкранных рабочих столах (Fullscreen Spaces) и внешних мониторах.

## 🚀 Установка

### Вариант 1: Готовый DMG (Рекомендуется)
1. Перейдите в раздел [Releases](../../releases).
2. Скачайте свежий `ICO.dmg`.
3. Откройте образ и перетащите **ICO** в папку **Программы** (`/Applications`).

### Вариант 2: Сборка из исходников
Требуется: macOS 14.0+, Xcode Command Line Tools (`xcode-select --install`).

```bash
# Клонируйте репозиторий
git clone https://github.com/infiniunbetatester/ico.git
cd ico

# Соберите приложение
./build_app.sh

# Или соберите DMG-образ для дистрибуции
./build_dmg.sh
```

## ⌨️ Горячие клавиши и управление

| Действие | Способ |
|---|---|
| **Раскрыть / Свернуть** | Наведение курсора на челку или клик по ней |
| **Закрыть раскрытый остров** | Клавиша <kbd>Esc</kbd> или клик вне челки |
| **Быстрое сворачивание/разворачивание** | <kbd>Cmd</kbd> + <kbd>D</kbd> (в меню трея) |
| **Закрепить открытым** | Иконка булавки в челке или кнопка Pin на Touch Bar |
| **Стиль свернутой челки** | Меню трея: *Компактная (24px)* / *Тонкая полоска (6px)* / *Невидимая* |

## 🔒 Разрешения macOS

Для полноценной работы некоторых функций приложению могут потребоваться стандартные разрешения macOS (настраиваются в **Системные настройки → Конфиденциальность и безопасность**):
- **Запись экрана**: требуется исключительно для инструмента «Текст с экрана (OCR)».
- **Аудио**: требуется для работы микшера громкости приложений.
- **Универсальный доступ**: для переключения окон в менеджере приложений.

> Приложение подписано локальной Ad-Hoc подписью, поэтому после однократной выдачи разрешений macOS не будет запрашивать их повторно.
