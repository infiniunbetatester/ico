## Обзор

> [!IMPORTANT]
> **Важное примечание о совместимости:** Приложение ICO создано и оптимизировано специально для компьютеров Mac **без встроенной аппаратной челки** (MacBook с Touch Bar, классические MacBook Air/Pro со сплошной рамкой, iMac, Mac mini, Mac Studio, Mac Pro, а также внешние мониторы). Оно добавляет на них стильную виртуальную челку и Dynamic Island. **Приложение не рассчитано на Mac с физическим вырезом в дисплее** (MacBook Pro 14"/16" и MacBook Air с челкой M2/M3).

ICO переносит опыт Dynamic Island и стильной челки на любые Mac-дисплеи, создавая интерактивный центр управления у верхнего края экрана:

```
       ┌───────────────────────────────┐
       │           ╭───────╮           │  <-- Dynamic Island / Челка экрана
       │           ╰───────╯           │
       │                               │
       │    [Плеер] [Утилиты] [Полка]  │  <-- Выдвижные интерактивные панели
       │   [Буфер]   [Приложения]      │
       └───────────────────────────────┘
```

## Ключевые возможности

### Управление музыкой и звуком
* **Динамический мини-плеер:** Обложка трека, бегущая строка с градиентными краями и адаптивный эквалайзер, берущий доминирующий цвет с обложки альбома.
* **Универсальный пульт:** Перехват звука на системном уровне. Работает с Apple Music, Spotify, Яндекс Музыкой, YouTube, Safari, Chrome и Telegram.
* **Расширенное управление:** Интерактивный ползунок таймлайна, громкость, случайный порядок и повтор трека.

### Экранные инструменты и продуктивность
* **Распознавание текста с экрана (OCR):** Выделение области при помощи `ScreenCaptureKit` и Apple `Vision`. Быстрое извлечение текста на русском, английском и системных языках с автокопированием в буфер.
* **Комплекс работы с QR-кодами:**
  * **Сканер с экрана:** Мгновенное считывание любого QR на дисплее с валидацией ссылок и открытием в браузере.
  * **Векторный генератор:** Создание четких QR-кодов из текста или буфера на базе `CoreImage` с экспортом в PNG.
* **Раздельный микшер громкости:** Регулировка громкости отдельных работающих программ независимо от общей громкости Mac.
* **Таймер с обратным отсчетом:** Компактный индикатор времени, звуковой сигнал и раскрытие челки по окончании.

### Работа с данными и файлами
* **Временная полка файлов (Shelf):** Зона у верхнего края дисплея для перетаскивания (Drag-and-Drop) файлов, картинок и папок между разными рабочими столами и окнами.
* **Умный буфер обмена:** История скопированного текста с индивидуальным удалением, поиском, полной очисткой и **отправкой в Telegram в 1 клик**.
* **Центр приложений:** Обзор всех запущенных окон с быстрым переключением фокуса.
* **Настройка окна (Always on Top):** Возможность отключить нахождение поверх всех окон, чтобы челка не перекрывала полноэкранные приложения.

## 🧩 Создание собственных виджетов (HTML / CSS / JS)

Каждый может создавать интерактивные виджеты для челки за считанные минуты. Виджеты запускаются в изолированном `WKWebView` с аппаратным ускорением и прозрачным фоном.

### 1. Где лежат файлы виджетов
Все виджеты хранятся локально в домашней папке:
```
~/.ico/widgets/<имя-виджета>/
├── widget.json   # Манифест (название, иконка, высота)
└── index.html    # Верстка, стили и логика
```
*(В панели виджетов есть кнопка **«📁 Папка»**, открывающая директорию в Finder).*

### 2. Манифест `widget.json`
```json
{
  "name": "Мой виджет",
  "icon": "sparkles",
  "description": "Пользовательский виджет для челки",
  "height": 260
}
```
*Поддерживается любая системная иконка Apple SF Symbols (`sparkles`, `cloud.sun.fill`, `timer`, `note.text`, `chart.bar.fill`).*

### 3. Нативный JS мост (`window.ico`)
Виджет взаимодействует с системой через объект `window.ico`:

| Метод | Описание | Пример |
|---|---|---|
| `window.ico.toast(message, icon)` | Показать всплывающее уведомление под челкой | `window.ico.toast('Сохранено!', 'checkmark')` |
| `window.ico.copy(text)` | Скопировать текст в буфер обмена macOS | `window.ico.copy('https://example.com')` |
| `window.ico.close()` | Свернуть остров | `window.ico.close()` |
| `window.ico.openURL(url)` | Открыть ссылку в стандартном браузере | `window.ico.openURL('https://binance.com')` |

### 4. Минимальный рабочий пример
```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <style>
    body {
      background: transparent;
      color: #fff;
      font-family: -apple-system, sans-serif;
      padding: 16px;
      user-select: none;
    }
    .card {
      background: rgba(255, 255, 255, 0.08);
      border-radius: 12px;
      padding: 14px;
      text-align: center;
    }
    button {
      background: #fff;
      color: #000;
      border: none;
      padding: 6px 14px;
      border-radius: 8px;
      font-weight: 600;
      cursor: pointer;
    }
  </style>
</head>
<body>
  <div class="card">
    <h3>Привет из ICO! 🏝</h3>
    <button onclick="window.ico.toast('Работает!', 'hand.wave.fill')">Нажми меня</button>
  </div>
</body>
</html>
```

## ✈️ Синхронизация буфера обмена с Telegram

ICO позволяет в 1 клик пересылать текст, ссылки или картинки из буфера обмена прямо в ваш Telegram (на телефон или планшет):

1. В шапке челки нажмите на шестеренку **«⚙️ Настройки»** справа.
2. В секции **«Синхронизация буфера с Telegram»** введите:
   * **Bot Token** (создается бесплатно за 30 секунд у [@BotFather](https://t.me/BotFather))
   * **Chat ID** (узнать персональный ID можно у [@userinfobot](https://t.me/userinfobot))
3. Нажмите кнопку **«Проверить отправку»** для проверки связи.
4. Теперь во вкладке **«Буфер»** у каждого скопированного элемента есть кнопка с самолетиком **«✈️»**, мгновенно отправляющая этот фрагмент в Telegram!

## Технические характеристики

| Компонент | Реализация |
|---|---|
| **Архитектура** | Чистый Swift 6.0, жизненный цикл AppKit, движок SwiftUI |
| **Платформа** | Universal Binary: `arm64` (Apple Silicon M1–M4) и `x86_64` (Intel Core) |
| **Минимальная ОС** | macOS 14.0 (Sonoma) или новее (проверено на macOS 15 Sequoia) |
| **Захват экрана** | `ScreenCaptureKit` для быстрого аппаратного захвата кадров |
| **Машинное зрение** | Apple `Vision` (`VNRecognizeTextRequest`, `VNDetectBarcodesRequest`) |
| **Генерация графики** | `CoreImage` (`CIQRCodeGenerator`) с четким векторным рендерингом |
| **Touch Bar** | Нативная поддержка через приватные связки `DFRFoundation.framework` |

## Установка

### Вариант 1: Universal DMG образ (Рекомендуется)

1. Скачайте свежий релиз со страницы [Releases](https://github.com/infiniunbetatester/ico/releases).
2. Откройте `ICO.dmg` и перетащите `ICO.app` в папку `/Applications`.
3. Запустите **ICO** через Spotlight или папку «Программы».

### Вариант 2: Сборка из исходников

Требования: macOS 14.0+, Command Line Tools или Xcode (`xcode-select --install`).

```bash
# Клонировать репозиторий
git clone https://github.com/infiniunbetatester/ico.git
cd ico

# Локальная сборка
./build_app.sh

# Или сборка дистрибутива DMG
./build_dmg.sh
```

## Управление и горячие клавиши

| Действие | Триггер / Сочетание | Описание |
|---|---|---|
| **Раскрыть / Свернуть** | `Наведение` или `Клик` | Открытие или закрытие основной панели челки |
| **Закрыть панель** | <kbd>Esc</kbd> или `Клик вне челки` | Сворачивание незакрепленного острова |
| **Экран Настроек** | `Кнопка шестеренки ⚙️` | Стили челки, Always on Top, Telegram мост |
| **Закрепить остров** | `Кнопка Pin 📌` или `Touch Bar Pin` | Предотвращает авто-сворачивание челки |
| **Размер полоски** | `Настройки → Стиль челки` | Стандартный (24px) / Тонкий (6px) / Скрытый (0px) |
| **Поверх всех окон** | `Настройки → Always on Top` | Отключает перекрытие других окон и фуллскрина |
